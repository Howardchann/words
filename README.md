## 这是什么

一个**个人自用**的雅思备考小程序：把 8115 个雅思高频词按词频从易到难排成课本式课程，配发音、例句、语法与复习。

做它的出发点很简单——准备考雅思、看看外企或海外机会，想有个能在地铁上刷两眼的工具。后来投入的时间远超预期，2026-10-20 停止。

## 主要功能

| 模块 | 做法 |
|---|---|
| 课程骨架 | **6 册 / 78 章 / 390 节**，每节 15~30 词；册章有标题，目录可逐级展开；每章末有「本章自测」（可选、不打卡、不占进度） |
| 词卡 | **一词一卡**：主义项之外的另一读音/词性合并进同一张卡（虚线区），音标、例句、变形各自可点读 |
| 词序 | 按词频排（`ai` 编号即词频排名），只换外层结构、不动词表顺序 |
| 发音 | **美音 + 英音**预生成 mp3，托管云存储、云函数签名分发；在线 TTS 仅作兜底 |
| 搜索 | 结果定位到「第 X 册 · 第 Y 章 · 第 Z 节」；搜到原形时下方给**百度式变形条**（use → uses / using / used），有独立词条的变形可直接跳卡 |
| 复习 | 间隔重复 1 / 2 / 4 / 7 / 14 / 30 / 60 / 120 天 |
| 进度 | **本地优先 + 云端合并**（云函数 `sync`，2.5 秒防抖）；可关闭同步；支持 JSON 备份导出 / 导入 |
| 工具页 | 查单词、音标速查 44 个、术语 81 条、语法 12 类 70 点、词形与构词 3 类 8 点 |

## 仓库结构

本仓库自 2026-09-27 起按**同仓 4 目录**划分实例（不是分支划分），四个实例同仓同 HEAD，功能一致，差异只在主题能力：

| 目录 | 实例 | 主题能力 | 状态 |
|---|---|---|---|
| `light/` | 主项 / 上线版 | 定死浅色 | **发布版本**，体验版只从它上传 |
| `cloud/` | 三色完整版 | 跟随系统 / 浅色 / 深色 | 保留色系调整模块；深浅切换的闪白/残影未根治，不用于发布 |
| `dark/` | 纯深色版 | 定死深色 | 与 light 同内核，仅外观层不同 |
| `original/` | 原始不发布版 | 无主题系统 | 2026-09-25 的冻结快照（`main@95f1a94`），不维护 |

每个实例都是**可独立打开的小程序项目**（开发者工具以实例目录为项目根）。每个实例有自己的 `AI-CONTEXT.md` 与 `CHANGELOG.md`；`cloud/` 的两份是完整决策史的权威来源。

## 技术说明（给想接手的人）

- **音频不在仓库里**：约 5.2 万条 mp3、约 1GB，全部托管在腾讯云存储（词 / 例句 / 英音 / 语法例句四个桶）。仓库里只有生成管线 `light/tools/audio-pipeline/`（脚本、输入数据、一份 5.1 万条的云端 key 清单），mp3 本身从未入 git——换音源就要全量重存，与「clone 下来就能调试」相冲突。
- **词库是唯一事实源**：`miniprogram/utils/words.js`（8115 条）+ `data-p1..p6.js`（每册的章 / 节 / 标题 / 目标）。节词数由 `SEC_N` 显式数组给出，**加词只需 push 一个数 + 补一条节标题**，不受任何倍数约束。
- **内容修正层**：功能词、异读音、副义项等修正集中在数据文件里，运行时代码只读不改写。
- **自检脚本**（`light/tools/`）：`verify-structure.js`（结构六项）、`validate-content.js`（词库与词形）、`validate-days.js`（骨架与进度映射）、`cloudsync-test/run_tests.js`（同步回归）、`audio-pipeline/selftest.js`（管线环境）。
